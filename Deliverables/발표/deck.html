03 / ALGORITHM
절단 알고리즘 ① 분류와 분할
정점마다 평면까지의 부호 거리를 구해 +, 0, − 세 상태로 나누고, 걸친 삼각형만 쪼갠다

3상태 분류

|d| ≤ ε 인 정점은 0 — 그 자체가 단면 위의 점 ●. 길이 0 선분이나 면적 0 삼각형이 생기지 않는다

교점은 에지당 한 번

양 끝 부호가 반대인 에지만 교점 ● 생성. 에지 캐시로 이웃 삼각형이 같은 점을 공유 → 틈 없음

위치와 속성 분리

위치는 Vertex 하나, UV · 법선은 Corner가 보간. UV seam이 있어도 양쪽 위치가 비트 단위로 같다
