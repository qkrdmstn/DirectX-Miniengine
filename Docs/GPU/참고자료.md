# 참고자료

확인일: 2026-10-23.

현재 조사 범위는 평면 절단과 GPU 단면 삼각분할이다. 기존 자유곡선 기반 절단 접근은 채택하지 않는다.
아래 문헌은 알고리즘 참고 자료이며, 현재 프로젝트의 GPU 절단 구현이나 성능 검증 결과가 아니다.

## 1. GPU에서 다각형들을 병렬 삼각분할

**Shadi Alawneh, Dennis Peters, “2D Triangulation of Polygons on CUDA.”**

- 발표: IEEE HPCS 2013, pp. 497–503.
- DOI: [10.1109/HPCSim.2013.6641459](https://doi.org/10.1109/HPCSim.2013.6641459).
- 원문: [저자기관 PDF](https://www.engr.mun.ca/~dpeters/papers/AlawnehPeters13a_hpcs2013.pdf).
- 확인 근거: 논문 원문.

CUDA kernel에서 다각형마다 스레드 하나를 배정한다. 각 스레드 내부에서는 ear를 하나씩 찾아 제거한다.
즉 여러 다각형 사이의 병렬화이며, 단일 다각형 내부의 여러 ear를 동시에 제거하는 구현은 아니다.
입력은 simple 2D polygon이고, hole 처리 지원은 이번 원문 확인에서 검증하지 못했다.

여러 절단면을 동시에 처리하거나, 삼각분할 결과를 CPU로 가져오지 않고 GPU에 유지하는 흐름의 참고 자료다.
단일 작은 절단면의 GPU 가속 효과를 입증하는 자료로 해석하지 않는다.

## 2. 한 다각형 내부의 ear 제거 병렬화

**Günther Eder, Martin Held, Peter Palfrader, “Parallelized ear clipping for the triangulation and constrained Delaunay triangulation of polygons.”**

- 게재: Computational Geometry 73 (2018), pp. 15–23.
- DOI: [10.1016/j.comgeo.2018.01.004](https://doi.org/10.1016/j.comgeo.2018.01.004).
- 서지·초록: [출판사 페이지](https://www.sciencedirect.com/science/article/pii/S092577211830004X).
- 확인 근거: 출판사 서지와 저자 공개 논문 원문.

Divide-and-conquer, partition-and-cut, mark-and-cut의 세 병렬화 방법을 다룬다.
독립적으로 제거할 수 있는 ear들을 선택해 한 다각형 안의 작업을 병렬화한다.
단, 구현과 실험은 CPU/OpenMP이며 GPU 구현 논문은 아니다.
Hole이 있는 입력에는 bridge를 삽입해 simple polygon 형태로 만드는 전처리를 사용한다.

단일 단면의 ear 제거를 병렬화하는 알고리즘 참고 자료다. CUDA나 HLSL 이식, GPU상의 동기화와
출력 관리가 검증되었다는 의미는 아니다. 작은 단면에서도 더 빠르다고 가정하지 않는다.

## 적용 범위 구분

| 항목 | CUDA 논문 (2013) | 병렬 ear clipping 논문 (2018) |
| --- | --- | --- |
| 실행 환경 | CUDA GPU | CPU/OpenMP |
| 병렬화 단위 | 여러 다각형 | 한 다각형 내부의 작업 |
| Hole 처리 | 지원 확인 못함 | Bridge 전처리 |
| 프로젝트에서 참고할 부분 | GPU에서 삼각분할 결과 유지 | 독립 ear 선택·분할 전략 |

두 문헌만으로 GPU 단면 생성 전체가 해결되지는 않는다. Ear clipping 이전의 절단 선분 연결,
폐곡선 구성, hole 판정과 이후의 렌더 출력 처리는 별도로 검토해야 한다.
