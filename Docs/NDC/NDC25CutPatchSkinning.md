# NDC25 절단 패치의 본 부착과 스키닝 해석

## 1. 결론과 적용 범위

**기존 패치 방식을 전제로 하면, 복사·절단해서 만든 Procedural mesh를 특정 본에 다시 붙이는 대신 정점별 스키닝으로 움직이자는 아이디어로 읽는 것이 가장 자연스럽다. [추론]**

- **[사용자 제공 대사]** 직접 확인되는 제안은 절단 부분의 정점에 스키닝 웨이트를 주어, 본에 다시 붙이지 않고 애니메이션하자는 것이다.
- **[추론]** 새로 웨이트를 부여해야 하는 핵심 대상은 절단으로 생성한 정점이고, 애니메이션할 대상은 이 정점들을 포함하는 복사·절단 메시다. 기존 정점의 스키닝 정보는 복사·보존해서 사용할 수 있다.
- 원본 스켈레탈 메시도 기존처럼 스키닝한다. 여기서 “Procedural mesh에 스키닝을 적용한다”는 해석은 원본의 스키닝을 없앤다는 뜻이 아니다.
- 대사에는 `Procedural mesh만`이라는 범위 한정이 없다. 원본을 포함한 전체 메시의 관리 구조까지 교체한다는 뜻인지도 이번 자료로 확정하지 않는다.
- **[슬라이드]** 발표자는 이 내용을 “아직은 아이디어 단계”로 표시했다. 구현 완료나 프로젝트 채택 결정으로 취급하지 않는다.

## 3. 기존 과정에 아이디어를 적용해 본 단계별 흐름

다음은 사용자가 정리한 기존 패치 절차에 제안을 적용한 설명용 흐름이다. 발표에서 이 순서와 세부 구현을 모두 명시했다는 뜻은 아니다. **[사용자 정리 + 추론]**

1. **자를 메시를 선택한다.**
2. **절단에 관련된 joint와 복사 범위를 정하고 패치를 복사한다.**
   - 기존 정점의 본 인덱스와 스키닝 웨이트도 보존한다. 어떤 joint를 선택하는지는 기존 선택 정책의 문제이며 이번 대사가 새 정책을 제시하지는 않는다.
3. **여러 패치를 함께 자를 경우 합친 뒤 절단하고, 메시 아일랜드를 구분한다.**
   - 중복 복사 방지와 아일랜드 탐색은 별도의 기하·관리 문제다. 스키닝 웨이트가 이 문제를 대신 해결하지 않는다.
4. **절단으로 생성한 정점에 본 인덱스와 웨이트를 부여한다.**
   - 본 하나만 따라갈 정점이라면 해당 본의 웨이트를 1로 표현할 수 있다. 어떤 정점에 어느 본을 지정할지, 혼합 웨이트를 어떻게 만들지는 이번 대사에 없다.
5. **선택한 joint를 분리하고, 원본에서 패치로 대체할 영역을 컬링·마스킹한다.**
   - 이번 아이디어만으로 기존 복사·원본 숨김 절차가 없어졌다고 보지 않는다.
6. **잘라진 Procedural mesh를 정점별로 스키닝한다.**
   - 복사한 기존 정점은 보존한 스키닝 정보를, 새 정점은 부여한 스키닝 정보를 사용한다.
   - 메시 조각 전체를 특정 본 하나에 붙이는 방식에 의존하지 않는다.
   - 분리 후 반대편 본의 영향을 끊거나 절단 시점 기여로 교체하는 처리는 별도로 필요할 수 있다. 기존 웨이트를 그대로 쓰면 모든 늘어남 문제가 해결된다는 뜻은 아니다.

흐름 요약: **메시 선택 → 패치 복사 → 필요한 패치 병합·절단·아일랜드 구분 → 새 정점 웨이트 생성 → joint 분리·원본 숨김 → 절단 패치 스키닝.**

## 4. “통 메시에서 버텍스 단위로 관리”의 의미

**[추론]** 합쳐서 절단한 메시를 본마다 다시 나누어 붙이는 대신, 그 메시 안의 정점마다 본의 영향을 표현하자는 의미로 읽을 수 있다.

| 움직임을 표현하는 단위 | 예시 |
| --- | --- |
| 메시 조각과 부착 본 | 한 조각에 몸통과 팔이 함께 있으면, 조각 전체를 어느 본에 붙일지 골라야 함 |
| 정점의 본 인덱스·웨이트 | 같은 메시 안에서도 몸통 쪽 정점은 몸통 본을, 팔 쪽 정점은 팔 본을 따라가도록 표현 가능 |

이렇게 하면 메시 조각 수와 본 그룹 수가 일대일로 맞아야 한다는 전제를 피할 수 있다. 다만 정점이 실제로 참조할 본과 분리 후 변환은 여전히 정해야 한다.

“통 메시”를 원본 캐릭터 전체라고 단정하지 않는다. 합쳐진 절단 패치를 가리키는지, 전체 관리 구조로 확장하려는지는 이번 두 이미지와 대사만으로 확정할 수 없다. 절단된 조각을 다시 연결한다는 뜻도 아니다.

## 5. 확정하지 않은 구현 세부

- 새 절단 정점·cap 정점의 웨이트 생성 방법: 단일 본 지정, 보간 등 구체적인 선택.
- 분리된 본 그룹 양쪽에 영향을 받는 기존 정점의 기여 교체·제거 방법과 좌표계.
- 메시 아일랜드와 독립적으로 움직이는 본 그룹의 소속·변환 관리 방법.
- Procedural mesh의 스키닝을 CPU와 GPU 중 어디에서 수행할지.
- 원본 메시를 포함한 전체 구조의 변경 여부와 원본 컬링 절차의 최종 형태.

이번 대화의 해석은 **“절단 결과를 본에 다시 붙이는 대신 정점별 스키닝으로 움직이자”**까지다. 웨이트만 추가하면 반복 절단·아일랜드·분리 후 변형 처리가 모두 완성된다는 주장이나, 전체 메시 교체 설계로 확대하지 않는다.
